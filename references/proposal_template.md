# Proposal 模板

## 模板结构

```markdown
# Proposal: [功能名称]

## 背景
- 解决的问题/痛点
- 业务场景描述
- 现有方案（如有）及其不足

## 目标
- 核心目标1（可量化最好）
- 核心目标2
- 预期效果

## 范围
### In Scope（本次实现）
- 功能点1
- 功能点2

### Out of Scope（本次不实现）
- 功能点A
- 功能点B

## 初步想法
### 功能描述
- 核心功能逻辑
- 用户交互流程

### 关键假设
- 假设1
- 假设2

## 风险与约束
- 技术风险
- 时间约束
- 依赖项

## 待确认问题
- [ ] 问题1
- [ ] 问题2
```

## 填写指南

### 背景
- 用2-3句话说明为什么要做这个功能
- 指出具体的用户痛点或业务价值

### 目标
- 尽量用可量化的指标描述
- 例如："将用户登录时间从3秒降低到1秒"

### In/Out Scope
- In Scope: 本次迭代要完成的功能
- Out Scope: 暂时不做但未来可能做的功能
- 明确边界可以避免范围蔓延

### 初步想法
- 描述你期望的功能是什么样的
- 不需要技术细节，只需要业务逻辑

### 待确认问题
- 列出所有需要和用户确认的问题
- 等待用户回答后再进入Spec阶段
